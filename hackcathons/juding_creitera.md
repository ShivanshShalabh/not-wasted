Judging Criteria
Communication: Can the team clearly and concisely communicate the future state they are creating?
Social Impact: Does the solution solve a meaningful problem and create measurable value?
Credibility: Does the team demonstrate grit, self-awareness, and the ability to execute?
Problem Validation Have real customers provided input? Is there evidence that the problem is worth solving?
User Experience Is the workflow intuitive? Can a new user understand it quickly?
Technicality Does the prototype actually work and leverage Oracle Cloud Infrastructure capabilities?
